# homebrew-minbar

Homebrew tap for [MinBar](https://github.com/oauramos/minbar), a macOS menu bar on SketchyBar.

```sh
brew install oauramos/minbar/minbar
minbar setup
```

The formula's source of truth is [`Formula/minbar.rb`](https://github.com/oauramos/minbar/blob/main/Formula/minbar.rb)
in the MinBar repo; each release copies it here.
